# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **Starbound**, please do **not** open a public issue. Instead, please report it confidentially by emailing:

**📧 security@webdevix.com**  
(Or replace with your preferred contact method.)

We will acknowledge receipt within **48 hours** and aim to provide a resolution within **7 days**, depending on severity.

---

## Supported Versions

| Version        | Supported |
|----------------|-----------|
| Latest release | ✅         |
| Older versions | ❌         |

We only provide security updates and patches for the **latest stable release** of Starbound.

---

## Security Measures

- All user inputs are sanitized and validated.
- Rate limiting and brute-force protections are implemented.
- Data is encrypted in transit (HTTPS) and sensitive information is encrypted at rest.

If you'd like to be credited after responsibly disclosing a vulnerability, please let us know and we’ll be happy to acknowledge your contribution.
